# BF Calendar Sharing - Nextcloud calendars

Lets each calendar sharing link (`bf_calendar_share`) choose which Nextcloud
calendars it shows (for example the work calendar, not the personal one), and
whether meetings that exist only in Odoo are included. A Nextcloud calendar can
be ticked by default for new links (*Shown by default in calendar links* on its
configuration). Installed automatically with both modules.
