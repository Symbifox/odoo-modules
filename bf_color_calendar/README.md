# Symbifox Color for Calendar (`bf_color_calendar`)

Bridge between [`bf_color`](../bf_color) and Odoo Calendar. Installs by itself
when both are present.

## What it does

Meeting types (the tags of an event) take a free color instead of Odoo's twelve,
shown on the event's tags in the list and the form.

## Requirements

Odoo 18 (`calendar`), `bf_color`.
