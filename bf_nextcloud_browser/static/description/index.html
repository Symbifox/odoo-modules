Nextcloud File Browser

Browse, preview, organise and share Nextcloud files — inside Odoo

A WebDAV file browser embedded on Odoo project and task forms, plus a standalone application. Two-pane (folder tree + listing) navigation, inline preview, drag-and-drop upload and move, configurable public share presets, and one-click open in Nextcloud for office documents.

  • Embedded Fichiers Nextcloud tab on projects and tasks
  • Standalone Nextcloud application and systray launcher
  • One Nextcloud account per person, connected once, revocable any time
  • Folder tree, sortable columns, inline modal preview
  • Upload (drag-and-drop, multi-file), folder, rename, move, delete
  • Configurable share presets (internal / external)
  • Link files to the Knowledge Matrix

Security by design

Every operation is gated by an access group, scoped to the record's folder, and validated against path traversal. Each person connects their own Nextcloud account through Nextcloud's Login Flow v2, single sign-on included: Nextcloud applies its own permissions, and every share link and activity entry carries the person's name. App passwords are stored encrypted, never reach the browser, and are revoked on disconnection or when the Odoo account is archived.
