# Symbifox Color for CRM (`bf_color_crm`)

Bridge between [`bf_color`](../bf_color) and Odoo CRM. Installs by itself when
both are present.

## What it does

- **CRM tags** take a free color (`#RRGGBB`), and each person can keep their own
  color for a tag.
- **Opportunities** can be colored by their tags with an automatic rule; the card
  of the pipeline shows the color on its edge.

## Requirements

Odoo 18 (`crm`), `bf_color`.
