# RSS Feeds: house banner (`bf_flux_branding`)

Installs itself when both `bf_flux` and `bluefox_branding` are present. The RSS
digest email then uses the house mail layout (logo, colours, footer), with its
own title in the banner — "Vos flux de nouvelles" — where every other email
shows the company name, so the digest is recognisable before it is opened.

The variant inherits the shared layout and only replaces that title: anything
that changes in the house layout follows. Other emails are untouched.
