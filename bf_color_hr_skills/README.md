# Symbifox Color for Skills (`bf_color_hr_skills`)

Bridge between [`bf_color`](../bf_color) and Odoo Skills. Installs by itself
when both are present.

## What it does

Skill types take a free color instead of Odoo's twelve. The skills of a type
keep reading Odoo's index, which follows the closest shade.

## Requirements

Odoo 18 (`hr_skills`), `bf_color`.
