Document Nextcloud Sync

Synchronise Odoo project documents to Nextcloud over WebDAV

Hardened WebDAV/OCS helpers for connecting Odoo to a Nextcloud instance: PROPFIND / GET / PUT / MKCOL and public share-link creation, with path sanitisation, SSRF protection and encrypted credential storage. Provides the configuration and file primitives reused by higher-level modules such as the Nextcloud File Browser.

  • Encrypted (Fernet) service-account credentials, key kept out of the database
  • HTTPS-only, private/link-local IP rejection (SSRF defence)
  • Path traversal sanitisation and prefix scoping
  • Public share links with expiry and optional password
  • Document upload wizard and project document integration
