# Python dependencies for the Blue Fox Odoo modules (Odoo 18.0).
#
# Two groups, because they carry different risk:
#
#   * Shipped by Odoo core — a floor only, so pip does not fight the version
#     already present in the Odoo image.
#   * NOT shipped by Odoo core — compatible-release pins (~=), so a module does
#     not silently follow a major upstream release it was never tested against.
#
# Every entry is declared by at least one module's `external_dependencies`, or
# imported directly by its code. Keep this file in step with those manifests:
# an undeclared dependency fails at install time with no useful message.
