# RSS Feeds: noticeboard (`bf_flux_babillard`)

A "Post to noticeboard" button on a retained feed item. It prepares a **draft**
noticeboard post (title, summary, link) addressed to the departments of the
lists that retained the item, or to everyone when none targets a department.
Drafts only, and only for the noticeboard editors: they decide what everyone
sees. One card per item, however many times the button is pressed.
