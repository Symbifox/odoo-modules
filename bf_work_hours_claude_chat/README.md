# BF Working Hours - Gen (`bf_work_hours_claude_chat`)

Bridge between **BF Working Hours** and **Gen**, installed automatically when both are.

A prompt the person types to Gen, on the web or on the phone, or a Gen pass they start with a
button (refining a meeting report or an agenda, reviewing a meeting, the editorial and process
mapping assistants), counts as a trace of their working time: the two minutes before it. Not its text. A prompt created through the person's
API key counts too: Gen cannot tell a typed prompt from a scripted one.

Not counted: assistant replies, directives posted on the person's behalf, nightly follow-ups,
and passes nobody typed (document reading, enrichment, titling).
